# ELMUAZ Portal Web App

The daily workspace for the **ELMUAZ** team. It gives everyone a clean, simple dashboard to track projects, submit deliverables, and review tasks based on their role.

## Highlights

- **Role Dashboards:** Clean views customized for Executives, Department Heads, Finance, and Employees.
- **Task Board:** Clear visibility across all stages (Draft, In Progress, Review, Needs Correction, and Done).
- **Submission & Feedback History:** An easy-to-read history dropdown right inside the task card showing past notes and reviewer feedback.
- **Action Triggers:** One-click approvals, rework requests, and final task closure.

## Built With

- Modern HTML5, CSS3, and JavaScript (Vanilla ES6)
- Connected via REST API to our backend service

## Connecting to the API

Set the API URL in your config file:
- **Local testing:** `http://localhost:3000/api`
- **Live production:** `https://elmuaz-core-api.onrender.com/api`
